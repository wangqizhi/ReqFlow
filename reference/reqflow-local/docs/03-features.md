# 功能说明

## 项目与需求

- 新建、直观切换项目；独立的项目背景、引导词、需求列表、Prompt 批次。
- 记录需求标题、正文、类型（功能/改进/缺陷）、优先级 P0/P1/P2、可选验收条件。
- 没有需求草稿环节；保存后进入待执行。已有待执行需求可编辑并延时自动保存；新需求需明确保存。
- 表单末尾可选择是否需要 AI 测试验证、编辑交付引导。项目设置提供新需求默认值，需求可单独修改。
- 已进入执行或待验证的需求不能直接编辑，需按流程取消或退回。

## 快速执行与人工验收

1. 在待执行列表选择需求，调整本轮顺序，生成并保存 Prompt 批次。
2. 复制或导出 Markdown，交给你使用的 AI/开发工具。
3. 点击“确认已提交给 AI”，需求进入执行中。
4. 开发完成后点击“实现完成”，进入待验证。
5. 自己检查结果：通过则直接归档；未通过可填写原因并退回待执行，下轮 Prompt 带入问题。

没有已验收中间环节，不要求填写 commit、验证环境、截图或测试证据。已归档内容支持回归退回，再次进入待执行。独立“协助验证”模式已移除；历史验证批次只保留查看。

## Prompt 工作台

- 包含项目上下文、引导词、本轮目标、需求正文、验收条件、未解决的失败问题和各自交付引导。
- AI 测试说明只针对开启验证的需求。关闭全部需求验证时，系统默认文案去除相关测试说明；手工写入的自定义说明不会自动删除。
- 生成保存快照与哈希，保留批次历史。源需求或引导变化后提示旧快照失效，可按最新内容重新生成。
- 复制和导出不改变状态；需要明确确认提交。已提交批次可取消执行。

## 手机操作

- 围绕 390px 手机视口做响应式布局，底部提供需求、Prompt、记录需求切换。
- 需求编辑弹窗使用可见视口高度、16px 输入文字及安全区，保存区域便于触达。
- 项目侧栏增强文字对比度、关闭入口与新建项目按钮。
- 验证开关使用较大滑块、绿色/灰色状态和“已开启/已关闭”文字。
- 成功提示位于顶部安全区，约 1.8 秒消失、不堆叠、不拦截点击。

具体机型、键盘和浏览器行为仍需本地设备验证。

## 数据与历史

按登录用户保存整个工作区；服务端保存和版本冲突检查；可在菜单导出全部数据为 JSON。历史记录追踪创建、编辑、提交、完成、验证、归档和回归。下载包提供本地命令行导入，页面目前没有导入按钮。

## 当前范围

该应用管理需求、生成 Prompt 和记录用户验收，不会自动调用大模型或自动运行测试。没有 Git 集成、团队权限配置、协作编辑、后台任务或消息发送功能。
