## 仓库与备份使用

先安装本机 Git，并配置 SSH known_hosts / ssh-agent 或系统 HTTPS 凭据管理器。SSH Key 选择现有私钥文件；不把私钥内容写入工作区。目标分支字段不自动切换本地项目分支。

备份推荐使用独立的私有仓库。初次可使用空仓库，或填入远程已有分支。自动同步只在 ReqFlow 桌面应用运行时每 60 秒触发；配置保存后下一个周期生效，也可立即同步。

备份上传 `reqflow-backup.json`，包含完整 workspace（含图片 dataUrl）、AI 供应商与调用 URL、备份设置和项目仓库配置。API Key 与 SSH 私钥文件不上传。数据目录中的备份检出独立于项目代码仓库；不强制推送，远程分支分歧时提示失败，保留本地待推送备份供排查。没有新数据时不会增加 commit；推送失败可重试。

恢复时下载 `reqflow-backup.json`，通过 CLI `workspace import --file <文件> --replace` 导入需求与项目设置；AI / 备份配置参照文件中的 settings 手动填写，API Key 需重新配置。

真实 GitHub / GitLab 账号连接需要使用者提供仓库与认证。自动检查使用临时 bare Git 仓库，不操作用户远程仓库。

便携版启动器可能不转发 stdout；脚本调用时可使用 `--out <结果文件>` 获取 JSON，安装版 CLI 可直接使用子进程管道。
