# ReqFlow 2.10.0

## 主要更新

- 功能转上下文会一并携带相关代码：Agent 阅读现有功能后，把关键代码摘录与源码路径通过 `context put --code/--files` 写入上下文库；上下文目录新增 `code/<上下文ID>.md`，并随 `contexts.md`、`index.json` 一起纳入 Git 版本管理。
- 上下文管理页支持查看、编辑和复制相关代码与相关文件，并显示 Git 版本管理状态；系统未安装 Git 时，页面直接提示安装方式与下载入口。
- 「项目与交付设置」浮层在默认桌面尺寸下不再出现滚动条；守则字数上限与「重新生成 / 删除守则」按钮同排对齐，底部保存区与各标签页按钮风格统一。
- 数据看板点击具体项目可进入里程碑视图：按时间倒序读取 Git 提交历史，以时间轴呈现每个提交的 commit log 文案、作者、短哈希与 HEAD/标签标记，并提供提交总数、参与作者与时间跨度统计；无目录、无 Git、无提交时给出对应引导。
- 桌面应用版本升级至 2.10.0（功能更新且影响文件范围超过 20 个）。
