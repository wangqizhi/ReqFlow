# ReqFlow 1.11.1

- 左侧恢复完整的“帮助 · CLI 参考”入口；最新版本用绿点提示，悬停可查看版本，点击可重新检测。
- 下载和安装的红色按钮独立显示在帮助入口下方，进度、提示及错误信息不再遮挡原有文案。
- 自动发布使用交付时确定的版本，不再重复升版；同步锁文件，并在上传前检查应用、安装版和便携版的内部版本。

本轮版本统一为 1.11.1。直接运行 `node scripts/publish.mjs` 会构建、打包并发布 1.11.1；上传失败可用 `npm run release:github` 重试。下一轮交付按需求数量确定新版本，并用 `npm version <版本> --no-git-tag-version` 同步版本，再执行构建或发布。
