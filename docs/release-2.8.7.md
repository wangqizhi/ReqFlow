# ReqFlow 2.8.7

## 主要更新

- REQ-176：独立终端首次加载与日志回放、窗口最大化或调整尺寸时显示加载过渡。尺寸稳定且日志完成渲染后再显示内容，减少闪烁。
- REQ-177：实验室开启 Terminal 后立即显示就绪终端，无需先发布；尚未发布时显示等待提示，发布后显示实时输出，保留收起、独立窗口与项目隔离行为。
- REQ-178：设置「同步备份」增加「从远端导入」。读取远端分支备份并补充缺失项目、需求、历史与上下文，相同 ID 保留本机内容，导入前保存恢复副本。导入不推送本机数据，远端执行锁不恢复；并发修改会拒绝写入。新配置自动同步默认关闭，尊重已保存的开关设置。
- REQ-179：更新远程项目执行设计，比较原受限桥接与新增的本地源码镜像、SSH 远端构建方案，补充同步屏障、快照、失败恢复及客户端引导词草案，保留架构选择待用户决定。

## 交付说明

本次为小功能调整与方案文档更新，影响文件少于 20 个，版本升级至 2.8.7。生成 Windows x64 安装包、便携版及 SHA256 校验文件，不自动安装或上传。

远端导入采用补充合并，同一 ID 不覆盖本机版本。恢复副本为数据目录的 `before-remote-import.json`，后续成功导入会更新该副本。未实施远程源码同步或远程执行架构。
