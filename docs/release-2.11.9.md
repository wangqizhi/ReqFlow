# ReqFlow 2.11.9

## 主要更新

- 指派 Codex / Pi / ZCode 的交互终端补充最大化按钮：点击后在独立窗口继续同一个会话，与发布终端一致。
- 独立窗口复用发布终端窗口，可输入沟通、停止会话；关闭窗口不结束会话，主界面标题栏的「Codex / Pi / ZCode 终端」按钮可把窗口切回前台。
- 最大化期间主界面隐藏停靠终端，窗口关闭后自动恢复；需求全部完成或移除时同时关闭独立窗口。
- 新增后端窗口生命周期测试，覆盖打开、状态查询、关闭与未知会话拒绝。
- UI 冒烟检查的脚本共用超时由 55s 放宽到 120s，避免较慢机器上紧凑布局阶段因超时中断。

## 验证

- `go test ./...` 与 `go vet ./...` 通过；新增指派终端窗口生命周期测试。
- `npx tsc --noEmit` 通过；`npm run check:mygo:ui` 界面检查全部通过。
- `npm run installer-check` 通过，安装器升级保留数据与旧组件清理均符合预期。
- 安装包 `release/ReqFlow-Setup-2.11.9.exe` 已生成，未自行安装。
- 交互终端的最大化需要在装有 Codex / Pi / ZCode CLI 的机器上人工点击验收。
