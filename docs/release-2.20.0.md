# ReqFlow 2.20.0

## 主要更新

- AI 需求聊天室在追问时一定会同时给出第一版候选需求，待确认的内容会在候选中标出。你回答后，AI 会按回答修改原来的候选，不用等人工回复后才生成需求。
- AI 需求对同一需求最多追问一轮。你回答后不再继续追问，没有答复的细节按改动最小的做法处理，并在候选说明中以「默认：」注明，你可以直接编辑修改。
- 上下文预览在过期前自动刷新，预览失败时自动重试。发送时如遇上下文失效，会自动重新准备并重发，不用手动点「刷新来源」。
- AI 需求聊天室记录每次回复使用的模型供应商和模型，显示在回复标题旁和 Token 用量栏，聊天历史中也能查看。
- 浏览项目窗口底部新增信息栏，显示选中文件或目录的完整路径、大小、权限、Windows 文件属性和修改时间，远程目录还会显示属主，路径可一键复制。
- Git Push 的过程输出实时显示在信息栏，包括推送进度和远端返回信息。完成或失败后保留结果，可展开查看并复制完整输出。
