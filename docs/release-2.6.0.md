# ReqFlow 2.6.0

## 主要更新

- 设置支持保存多套 AI 配置，新增、修改、删除后统一保存；选择配置并保存即可切换当前供应商。旧单套配置自动显示为第一套配置，所有 API Key 继续使用本机加密保存，不进入工作区导出与远程备份。
- 新增 Codex、ZCode、Pi、Claude Code 本地 CLI 供应商，支持安装与版本检测、重新检测及可选模型。保存后复用本机 CLI 登录，可用于需求整理、讨论、引导词优化及 Git 提交文案生成。
- CLI 使用非交互模式，在临时目录处理内容，设置两分钟超时及输入/输出大小限制。Codex 使用只读沙盒，Pi 与 Claude 关闭工具；ZCode 使用 guarded 模式及请求附件。命令不可由用户自由指定，正文不拼接为 shell 命令。
- 可读取近期 Codex 本地会话中的账户额度快照时显示周/月用量、更新时间与重置时间；没有可靠数据、快照过期或窗口不匹配时隐藏。其他 CLI 暂不显示无法获取的周/月额度。
- 设置改为左侧功能菜单与右侧整页内容，支持 AI 供应商、需求模板、同步备份、请求日志和数据分类；正文独立滚动，保存操作固定在底部，保存后继续停留在设置页。
- 「导出全部数据」移到「设置 → 数据」，导出时重新读取完整工作区，更新删除项目与帮助中的入口提示。

## 使用说明

CLI 需要先在终端完成安装与登录。设置中的检测仅检查命令可用性与版本，不能代替登录和真实生成检查；模型留空时使用 CLI 默认模型。ZCode 需要支持 `--print`、`--attach`、`--mode guarded` 和 `--output-format json` 的版本。

在 AI 供应商页点击「新增配置」，选择 API 服务或本地 CLI，填写配置名称和所需字段，然后点击「保存设置」。切换配置同样需要保存；离开设置前请保存本页修改。

## 验证与交付

包含配置迁移、密钥加密、多套配置切换、失败保存保护、四种 CLI 的 Windows 包装器与中文/特殊字符输入、非零退出处理及额度快照过滤检查。WebView 检查覆盖侧栏导航、配置保存与重新打开、完整数据导出，以及 1440×900 / 1440×720 下的 API、CLI 和数据设置布局。

交付 Windows x64 安装版、便携版与 SHA256 校验文件；不自动安装或发布。
