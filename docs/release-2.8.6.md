# ReqFlow 2.8.6

## 主要更新

- REQ-172 验证修复：「新建项目」固定在项目滚动列表下方；文件夹与已有项目独立滚动，标题、管理按钮和新建入口保持可见，整个分组仍最多占侧栏高度的一半。
- REQ-173 验证修复：在终端关闭按钮旁增加独立窗口按钮。点击后终端切换为可拖动、调整大小和最大化的原生桌面窗口，释放主窗口底部空间；关闭独立窗口后自动恢复停靠显示，不会中止发布。
- REQ-175：终端显示运行中的旋转加载图标、当前阶段和计时器；发布结束后显示成功或失败图标，并固定显示本次发布总用时。收起、切换项目或独立窗口时继续使用同一会话的起止时间。
- 独立终端共享已有输出缓存，保留 stdout、stderr、ANSI 和日志回放；Git / AI 阶段、失败结果与结束状态通过内存会话同步，避免异步返回的旧状态覆盖新状态。

## 交付说明

本次为小功能与样式调整，影响文件少于 20 个，版本升级至 2.8.6。生成 Windows x64 安装包、便携版及 SHA256 校验文件，不自动安装。

计时范围从点击发布后实际启动流程开始，包含发布前的 Git / AI 步骤。终端当前仍为输出查看，尚不提供交互式 Shell。
