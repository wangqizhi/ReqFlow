# ReqFlow 2.9.3

## 主要更新

- 新增 ReqFlow Agent OpenCode 插件，支持按当前目录匹配项目，领取 AI 排期需求，完成后逐条回写为待验证，保留人工验收流程。
- 插件版本查询、打包分发与 AI 任务领取增加 OpenCode 宿主和客户端标识，执行中页面与数据看板可展示 OpenCode 执行状态。
- OpenCode 插件支持版本检查与更新，并补充安装、配置及使用文档。
- 桌面应用小版本升级至 2.9.3；新增 OpenCode 插件版本为 0.1.0。
