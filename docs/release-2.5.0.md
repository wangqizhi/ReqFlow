# ReqFlow 2.5.0

## 主要更新

- 项目隐藏：悬停项目时可在删除按钮旁隐藏项目；隐藏保留全部需求与执行记录。
- 项目管理：在「我的项目」右侧打开管理浮层，搜索全部项目、恢复隐藏、调整组内排序，并一键切换分组；调整自动保存，重启后保留。
- 引导词编辑：修复项目设置中「项目引导词」和「默认交付引导」点击编辑后输入框过窄的问题，编辑区现在铺满可用宽度。
- 发布说明：发布前校验当前版本的更新文档，要求有明确的功能或修复列表；缺失或仅有安装说明时停止发布。补传已有 Release 附件时同步更新版本说明。

## 安装与升级

- Windows x64，Go/MyGO 独立应用，需要系统 WebView2 Runtime。
- `ReqFlow-Setup-2.5.0.exe` 为保留原数据的安装升级版。
- `ReqFlow-Portable-2.5.0.exe` 为单文件绿色版。
- 下载后可使用 `SHA256SUMS-2.5.0.txt` 校验文件完整性。
