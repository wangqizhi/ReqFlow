# ReqFlow 2.17.0

## 主要更新

- 验证、归档、保存需求、保存设置等操作明显提速：大项目单次保存从约 2 秒降至约 0.1 秒，后台刷新不再整份重传工作区数据。
- 需求图片保存后存放在数据目录 images 中，工作区只记录图片位置，界面按需加载；远程同步、备份、归档导出与工作区导出仍完整包含图片，旧数据在首次保存时自动转换。
- 保存时只写入实际变化的需求与项目，界面只接收有变化的项目；历史快照在界面中只加载标题、正文与验收标准，完整快照仍保留。
- 终端收起时发布，信息栏上方实时显示发布输出的最新内容，点击即可展开发布输出查看完整日志。
- 修复「从编辑器打开」无法打开 VS Code 的问题，VS Code 现以新窗口正常显示项目文件夹。
