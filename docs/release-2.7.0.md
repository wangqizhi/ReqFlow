# ReqFlow 2.7.0

## 主要更新

- 引导词 AI 优化要求精炼、条目化，仅补充必要信息，避免增加上下文占用。
- 本地 CLI 模型支持从 Codex 模型缓存和 Pi 可用模型列表选择，支持筛选、手工填写和默认模型。按已读取的模型能力显示思考等级，默认关闭；不能关闭的 Codex 模型使用其最低等级并在界面提示。Claude Code、ZCode 或读取失败时保留默认/手填模式，不编造模型列表。
- 设置返回项目菜单时检查全部分类的未保存内容，提供继续编辑、放弃更改和保存并返回。保存失败保留输入与浮层，已保存内容不重复提示。
- Windows 发布成功和失败均请求有声通知。修复成功被设为静默、系统通知声音映射为空时仍依赖 Shell 自动发声的问题：使用配置的提示音文件，缺失时回退 Windows 内置通知音，通过系统通知音频会话播放；显式静默通知仍不播放声音，系统音量和静音设置仍生效。
- 发布需求默认模板区分客户端分发/自动更新和网页服务部署/守护/重启/健康检查，参考 ReqFlow 与 release-watch 的现有流程。旧默认模板自动升级，自定义模板保持原文。

交付为 Windows 安装包与便携版，不自动安装。音频接口检查只能确认系统接受播放，实际听感需在用户设备上验收。
