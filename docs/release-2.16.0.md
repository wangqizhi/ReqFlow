# ReqFlow 2.16.0

## 主要更新

- 新增全局记忆：跨项目记录最近完成与执行中的需求、项目简介与目录位置，并可手动维护常用技术方案、UI 设计要求、偏好与协作习惯、工程约定、经验与踩坑、环境与常用命令。
- 设置新增「全局记忆」分类，可查看和编辑记忆内容，配置预留大小（默认 100 KB，可设 10–1024 KB）与最近工作条数，并显示用量与记忆文件目录。
- 记忆内容生成 Markdown 文件保存在数据目录 memory/ 下，超出预留大小时自动省略较早记录；开启后，排期、指派与复制的开发 Prompt 末尾会引用这些文件，开发 AI 会在实现前先阅读。
- 新增 CLI 命令 memory show，各 Agent 插件领取任务时一并返回全局记忆文件列表。
- 开发完成说明取消 50 字限制，完整保存并在待验证卡片中显示，内容较长时在卡片内滚动查看。
- 修复记录新需求时点击「放大编辑」后输入框没有变大的问题，放大框现在占据弹窗大部分高度。
- 排期表底部操作区精简文案，与类型筛选、搜索框保持在同一行显示。
