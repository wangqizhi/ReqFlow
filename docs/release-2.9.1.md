# ReqFlow 2.9.1

## 主要更新

- REQ-184：「功能转上下文」生成的需求改为只说明上下文与该功能的联系，不要求整理完整架构，保持精简。
- REQ-185：项目守则默认严格限制在 500 字，可在项目设置中调整上限（50–5000 字）；守则仍自动加入排期 Prompt，预览中显示当前字数与上限。
- REQ-186：打开记录新需求弹窗时，应用顶部保留可拖动窗口的标题区与最小化、关闭按钮。
