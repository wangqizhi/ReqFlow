# ReqFlow 1.2.3

- 提交文案提示词改为描述用户可见的最终行为、合并重复改动、保留 feat / bugfix / update 分类，禁止需求编号和追踪 ID。请求数据不再携带需求编号，并清除草稿和返回文案中的 REQ 标识。
- 当前本机模型已按用户指定改为 `deepseek-flash`；新配置默认预填该模型，已有其他自定义模型保留。使用当前服务配置实际调用成功，返回不含 REQ 编号的标准文案。
- AI 请求日志默认开启。在设置新增「请求日志」标签页，以终端样式展示发送时间、请求标识、协议、模型、HTTP 状态、各阶段累计耗时（毫秒）。SEND 表示发送，RESPONSE 表示收到响应头，DONE 表示响应正文接收、解析和格式处理完成，ERROR 表示失败。相同请求标识可用于对应各阶段。
- 关闭开关后点击「保存日志设置」停止记录后续请求，已有记录保留可查看。配置与日志仅保存在本机，远程备份不包含这些文件。
- 日志文件为实际数据目录下的 `ai-request-log.json`，保留最近 500 条记录。不保存密钥、调用 URL、需求正文或响应文案。查看日志时每 2 秒刷新。日志写入失败不影响生成结果。

验证通过：TypeScript、构建、Electron UI 集成、两种 AI 协议请求、去除编号、日志阶段与耗时、错误记录、关闭日志后的请求不再写入、日志持久化和开关保存、实际 deepseek-flash 服务调用、安装包构建和内容检查。界面截图位于 `out/review-1.2.3/ai-request-logs.png`。

安装包：`release/ReqFlow-Setup-1.2.3.exe`、`release/ReqFlow-Portable-1.2.3.exe`。
