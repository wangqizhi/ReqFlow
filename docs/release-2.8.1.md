# ReqFlow 2.8.1

## 主要更新

- 侧栏取消「远程项目」独立分组，远程项目与其余项目一起显示在「我的项目」的各文件夹中；远程项目使用服务器图标区分，并在名称旁保留连接状态点（在线绿点、断联红点，悬浮可看断联原因）。
- 项目排序与置顶的分组规则同步调整：同一文件夹内的本地与远程项目可以互相拖拽排序、置顶，不再按本地/远程拆分。
- 浏览项目中「更换本地目录」与「连接远程服务器」合并为一个「关联目录设置」按钮：弹窗显示当前关联目录，可改绑本地文件夹、连接或更换远程目录、取消关联；本地与远程目录只能绑定其一，绑定新目录会替换当前关联。

## 使用说明

远程目录仍为只读预览，本机 Git、编辑保存等本地能力对远程项目保持禁用。未关联目录时点击「选择项目目录」同样进入「关联目录设置」，可二选一绑定。

本次为小功能与界面调整，影响文件少于 20 个，按交付约定升级小版本至 2.8.1。提供 Windows x64 安装包和便携版，不自动安装。
