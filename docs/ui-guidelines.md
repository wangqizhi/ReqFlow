# ReqFlow UI 规则手册

适用于所有新界面与现有界面修改。基础样式位于 `src/renderer/styles.css`，图标复用 `src/renderer/icons.tsx`。

## 色调与层级

- 背景使用 `--bg`，面板使用 `--panel`，正文使用 `--ink` / `--ink-2`，说明使用 `--muted`。
- 橙色 `--accent` 为主操作与选中状态；绿色仅表示成功；红色仅表示错误与删除。不要为普通操作引入新色系。
- 面板圆角 10–14px，控件圆角 7–8px。浮层使用现有 `.overlay` / `.dialog` 与阴影。
- 标题 17–18px，正文 13–15px，辅助说明 12–13px；使用系统中文字体，不混用字体。

## 间距与对齐

- 同一操作组采用 flex、`align-items: center`、10–12px 间距；按钮不可紧贴，也不可因旁边提示而错行。
- 独立操作组之间留 16–20px，字段间留 13–16px，面板内边距 20–24px。
- 错误、过期提示与长说明放在按钮组下一行，不插入组内占位。
- 桌面默认窗口 1440×900；按钮、类型和优先级名称保持一行。按钮使用 `white-space: nowrap` 与 `flex-shrink: 0`，不要用缩小字号挤压文字。
- 长路径、文件名可以省略显示并用 title 提供完整内容；需求正文和错误说明正常换行，不截断关键信息。

## 控件与交互

- 按钮复用 `.btn`、`.primary`、`.sm`、`.icon-btn`；每组突出一个主要动作，其他动作使用普通按钮。
- 插件、设置和上下文管理的侧栏二级菜单使用 `.side-menu`，与首页「我的项目」标题 `.side-label` 共用文字样式：系统中文字体、11px、400 字重、20px 行高、0.12em 字间距、`--side-muted` 灰色；返回菜单、当前菜单与其他菜单保持一致，选中态只改变背景，不改变文字颜色、字号或字重。项目列表名称与新建项目继续使用 `.side-project` 的 14px 正文样式，计数继续使用 `.small-count`，不能依赖 button/div 的默认字号。
- 列表与卡片的操作按钮（复制、编辑、删除等）统一 `.btn` 常规尺寸；卡片内的删除用普通按钮加 Trash 图标，红色实心 `.danger` 只出现在确认弹窗中。
- 有限选项（类型、优先级、平台）使用 `.segmented` 合体选择按钮，附 `aria-pressed`；不露出原生 radio 外观。标签类动态筛选使用同视觉语言的 `.tag-btn`（可换行排布），选中态为 `--accent-soft` 底色加 `--accent` 描边，不用橙色实心表达选中。
- 列表页底部工具栏一行内：筛选（`.segmented`、`.tag-btn`）与搜索框靠左，排期 / 提交验证等操作键靠右；两侧顶部对齐，不因一侧换行错位。
- 输入框与 textarea 必须使用 `.field` 的统一边框、内边距与 focus 样式。使用语义 HTML，但不要展示浏览器默认文件控件或裸 select/radio。
- 图片选择保留隐藏 file input，用自定义带图标按钮触发；上传格式、数量与大小限制放在辅助说明中。
- 密钥显示按钮使用眼睛图标，放在输入框右侧内部；设置输入框右内边距，避免文字覆盖图标。
- 引导词等长文本默认以只读文本块展示（外观与输入框一致以示可点），点击进入更大的编辑框；焦点离开字段且无进行中的 AI 任务时自动收起为文本块。
- 引导词等长文本输入支持 @ 文件补全：目录列表按需加载并缓存，输入过程只在内存中过滤，下拉最多渲染约 30 项，超出提示继续筛选；键盘 ↑↓ 选择、回车确认，Esc 只关闭列表不关闭外层弹窗。
- AI 优化结果用上下两个文本框对比：上面只读展示原文，下面是可编辑的优化稿，「应用 / 放弃」按钮放在对比区底部；优化按钮与输入框标题同行靠右，加载中禁用并显示进度文案。
- 开关复用 `.switch`；图标复用 16–20px 线性 SVG，禁止同页面混用彩色图标与线性图标。
- 所有图标按钮有 `aria-label`，键盘 focus 可见，按钮有 disabled 状态，保存失败保留输入；异步操作防重复提交。

## 弹窗与滚动

- 新需求页默认只显示类型、优先级、正文；高级字段折叠，展开后使用两列，保持页内保存按钮可见。
- 1440×900 下新需求页（包括高级设置与最多 12 张缩略图）不出现弹窗滚动条；大量附件只在缩略图区域横向滚动。
- 全局设置使用侧栏二级菜单与右侧整页内容，正文独立滚动、保存操作固定在底部，保存后停留当前页；项目设置等浮层继续按功能分 tab，保留独立操作区。
- 长列表在自己的内容区滚动；不要仅靠隐藏 overflow 来掩盖不可访问的字段。较窄预览窗口允许降级换行与弹窗滚动。

## 交付检查

检查默认桌面尺寸与较低窗口高度；打开高级字段，填入长中文文案，添加多张图片；确认按钮同高同线、选项不换行、输入无覆盖、保存按钮可见。验证键盘选择、密钥显示切换、加载/失败/禁用状态。每次新建页面按本手册复用控件。
