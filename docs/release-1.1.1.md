# ReqFlow 1.1.1

本轮完成 REQ-029、REQ-030 共 2 条需求，按「不超过 3 条增加小版本号」从 1.1.0 升至 1.1.1。

- REQ-029：记住上次使用的项目。切换/新建项目时即记录，关闭程序后下次打开默认进入该项目；项目已被删除时自动回退到第一个项目（数据保存在本机 localStorage，不进入 workspace 备份）。
- REQ-030：浏览项目中的文件支持右键菜单，包含三项：复制文件名、复制完整路径（按关联目录的分隔符风格拼接）、从资源管理器查看（复用查看器已有的定位能力）。菜单顶部显示文件名（悬停可见完整名称）；点击菜单项、点击其他位置或按 Esc 关闭，Esc 不会误关整个浏览浮层。

## 使用说明

- 上次使用的项目在各窗口间共享：排期、提需求等操作均在当前项目进行，下次启动自动恢复。
- 右键菜单在文件树中的文件上触发；「复制文件路径」复制的是文件在本机的绝对路径，可直接粘贴到终端或编辑器。「从资源管理器查看」会打开系统资源管理器并定位选中该文件。
