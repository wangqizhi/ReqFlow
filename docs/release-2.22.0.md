# ReqFlow 2.22.0

## 主要更新

- 左侧项目栏支持在「按分组」与「最近项目」两种排序方式间切换；切换为「最近项目」后按项目最近活动和访问时间倒序展示，并在每个项目条目下清晰标注所属分组。
- Local Agent 新增 Antigravity（`agy`）支持：可自动检测本机 `agy` 安装与版本，在 Local Agent 面板开启后即可在排期表「提交验证」弹窗中指派给 `agy` 在交互终端执行。
- 数据看板改为标签页布局，将「需求趋势」「AI 执行」「项目分布」「Token 消耗」「每日明细」分块展示，保留顶部时间范围筛选与核心指标概览，减少长页面滚动。
- 设置页新增「快捷键」分类，首个快捷键支持配置「新建需求」（默认 `Ctrl+N`），提供手动输入修改、实时按键捕获以及恢复默认功能。
- 修改项目引导词或需求源内容变化导致排期过期时，排期表提示条新增「重新排期」按钮，点击即可一键以最新内容重新生成并提交当前排期，无需手动退回重排。
