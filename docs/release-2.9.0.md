# ReqFlow 2.9.0

## 主要更新

- REQ-181：修复新需求说明的 @ 文件补全被弹窗裁剪及撑出滚动条的问题。补全列表独立于弹窗渲染，根据可用空间向上或向下展开，保留键盘选择与 Esc 关闭。
- REQ-182：修复 UI 测试与日常应用共用 WebView2 浏览器配置的问题。测试隔离实际浏览器配置目录，Terminal 开关保存到应用数据文件，重启后恢复；兼容首次读取原有本地设置。
- REQ-183：记录新需求菜单增加“功能转上下文”。指定现有功能后生成需求草稿，引导 Agent 总结架构、功能文档及参考代码，并通过 context put CLI 提交到上下文管理。
- 上下文可关联项目与功能，自动生成只读 Markdown 项目守则，提供守则预览，并加入后续需求 Prompt。
- 设置中支持配置和迁移上下文目录，保留原目录为恢复副本；检测到 Git 时，每次上下文变化自动记录提交，迁移保留 Git 历史。目录或 Git 同步失败会提示，工作区中已保存的内容保留。

## 验证

- TypeScript 类型检查、Go 全量测试与 vet 通过。
- 上下文 CLI、守则拼接、目录迁移、Git 历史和 Terminal 持久化回归测试通过。
- 独立数据及浏览器配置下的 MyGO UI 检查通过，包括补全浮层可见性、Esc、功能转上下文、默认尺寸与低窗口高度布局。

## 交付说明

功能更新涉及超过 20 个文件，版本升至 2.9.0。生成 Windows x64 安装版、便携版与 SHA256 校验文件，不自动安装。
