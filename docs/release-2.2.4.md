# ReqFlow 2.2.4

- REQ-133 验收修正：窗口控制区固定在右上角，工作区标签、项目名和简介贴近顶部，保留 12px 间距；操作按钮留在窗口控制区下方。
- REQ-135 验收修正：全部 Tab 的操作和搜索筛选统一固定在列表底部。排期的日期范围放在底部操作栏上方，主要按钮和搜索框保持同一位置，列表独立滚动。
- REQ-136：新增仅在实际领取任务时显示的“执行中”Tab，展示 Codex、ZCode、Pi、开始时间与实时用时。ReqFlow 事务独占领取，同一任务不会被另一客户端覆盖；完成需提供所属运行记录并保存结束时间和用时。中断任务提供确认释放入口，释放后原客户端不能再提交完成。
- REQ-136 插件：Codex 0.4.0、ZCode 0.3.0、Pi 0.3.0。执行使用 `read`，只读查看使用 `inspect`；限定需求使用 `--ids`。Pi 的 `reqflow_read` 只有明确授权执行时设置 `execute=true`。兼容上一版领取快照的安全升级及分次回写。
- REQ-137：Windows 通知成功显示后播放一次系统信息提示音，禁用隐式重复音效；`Silent` 通知继续保持静音。

验证包括 TypeScript、Go 测试/vet、三个真实桥接客户端对 SQLite 的竞争领取、独占完成与释放、旧快照分次迁移、桌面布局和实时计时、Windows 声音调用与静音选项、更新包校验及宿主升级、安装包版本和 SHA256。

产物：`release/ReqFlow-Setup-2.2.4.exe`、`release/ReqFlow-Portable-2.2.4.exe`。
