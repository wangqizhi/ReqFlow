# ReqFlow 2.12.1

## 主要更新

- 修复独立 Linux 服务端不识别 `server run` 命令的问题，兼容带 `server` 前缀和直接使用 `run` 的两种调用方式，解决 SSH 上传成功但进程立即退出的问题。
- Server Agent 直接连接配置的服务端地址，避免继承本机 HTTP/HTTPS 代理导致内网服务连接失败，同时确保自签证书指纹检查使用直接 TLS 连接。
- 修复 SSH 安装生成的 systemd 用户服务：移除 ExecStart 中无效的 Shell 重定向，先写入配置，再执行 daemon-reload、启用并启动服务；仅在 systemd 不可用时回退到 crontab 与后台进程。
- SSH 安装完成后增加 HTTPS 健康检查；端口不可达或服务启动失败时返回明确错误，避免仅上传成功就提示安装成功。首次证书指纹确认仍由用户完成。
- 延续安装包检查：强制包含 Linux amd64 / arm64 服务端文件并核对大小与 SHA256。
- SSH 更新服务端时先上传临时文件再替换，避免直接覆盖正在运行的 Linux 程序导致上传失败。

## 验证

- 回归覆盖服务端命令前缀、代理隔离、证书信任与指纹变化、服务启动健康检查和 systemd 配置格式。

## 安装

- 使用 `ReqFlow-Setup-2.12.1.exe` 升级桌面端，再执行 Server Agent 的 SSH 自动安装。
- 升级保留现有本地数据。
