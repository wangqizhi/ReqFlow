# ReqFlow 2.11.7

## 主要更新

- Codex 在开启「指派」后默认出现，实验室保留调起 Codex 桌面窗口功能。
- Local Agent 集中管理 Codex、Pi、OpenCode、ZCode；前三者支持检测安装及版本、安装和更新，ZCode 仅检测官方安装。
- ZCode 支持单条及合并需求的任务执行，提供只读流式日志、任务文件传参、显式 build 权限、运行时限及进程树取消。需求仍由插件原子领取并回写待验证，保留人工验收。
- ZCode 需完整的官方 CLI 资源以及有效的模型和登录配置；自定义入口可通过 `REQFLOW_ZCODE_CLI` 指定。当前机器的官方安装缺少 provider 配置资源，尚未验证真实模型端到端执行。
- 安装向导首次显示在鼠标所在屏幕的工作区中央。
