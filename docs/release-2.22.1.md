# ReqFlow 2.22.1

## 主要更新

- 数据看板整页固定高度，不再出现竖向滚动条；切换「需求趋势」「AI 执行」「项目分布」「Token 消耗」「每日明细」标签时页面不再跳动。
- 「最近项目」排序只在项目有新建需求或完成验证（通过或未通过）时更新，点击切换项目不再把项目排到最上面。
- 「插件/MOD/AGENT」并入设置：Local Agent、Server Agent、实验室以原名称作为设置分类；「插件 / MOD 说明」移入帮助。
- 帮助改为标签页显示，分为快速上手、CLI 参考、Agent 对接、插件 / MOD 说明、数据与备份。
- 左侧项目计数显示为红色时只统计待验证需求数量，其他需求不再计入。
- 按 `Ctrl+N` 或点击「记录新需求」打开弹窗时，焦点默认落在需求说明输入框。
- 设置新增「通用」分类，可配置默认项目目录；配置后新建项目填写名称时自动补全为「默认项目目录\项目名称」，未配置时目录留空。
- 点击「新建项目」直接打开项目详情表单，不再先选择导入或本地创建；「导入项目」改为表单内的按钮。
- 项目目录旁的终端 CLI 按钮单击弹出 CLI 选择浮层（默认选中项目设置中的 CLI），双击直接打开默认 CLI。
- 统一全部弹出浮层的标题、说明文字、按钮排列、圆角与阴影样式，以「有任务正在执行」关闭确认框为基准。
- 新增配色切换：经典（原配色）、奶油、暗色（参考 VS Code Dark+），可在「设置 → 通用」中切换，独立终端与浏览窗口同步生效。
