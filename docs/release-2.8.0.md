# ReqFlow 2.8.0

## 主要更新

- 新建项目与浏览目录支持免密 SSH 连接服务器，浏览远程目录后绑定项目；复用本机 OpenSSH 默认密钥、SSH Agent 和 known_hosts。
- 远程项目显示在协作项目下方，定时检查连接，失败时显示红色断线标识；支持远程目录树、文本、Markdown 和图片只读预览。
- 管理项目使用置顶和鼠标拖拽调整排序，移除上移、下移按钮；侧栏同组项目支持拖到目标项前后，保留拖入文件夹的分组功能，排序自动保存。
- 新增远程 Codex 插件接入本机 ReqFlow 的设计讨论稿，涵盖 SSH 桥接、项目身份、独占领取、断线恢复及运行转交，供评审后决定是否实施。

## 使用说明

服务器需要启用 SFTP。本机需安装 OpenSSH，并提前在终端完成主机指纹核对和免密登录配置；目前不支持密码登录。远程目录只读预览，不执行远程 Git、发布或 Agent 派发。

本次增加远程目录功能并涉及超过 10 个文件，按交付约定升级中版本至 2.8.0。提供 Windows x64 安装包和便携版，不自动安装。
