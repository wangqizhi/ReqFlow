# ReqFlow 2.8.3

## 主要更新

- REQ-169：需求与 AI 执行统计从实验室移到左侧「插件/MOD/AGENT」下方的「数据看板」，保留现有统计、时间范围与明细表。
- 增加 GitHub 风格的绿色日历，展示过去 365 天每天新建需求的数量，支持项目筛选、悬浮提示、点击查看和方向键导航；日历固定展示过去一年，原有时间范围控制折线图与统计指标。
- REQ-170：「关联目录设置」弹窗调整为约 580px 宽，增加标题图标、浅灰目录信息区、目录名称和完整路径复制。保留白色背景、橙色主按钮及灰白辅助操作，优化长路径换行、按钮间距和系统深色模式下的局部配色。
- 界面检查会先清理隔离副本中的既有运行记录，避免真实执行中的任务干扰固定测试场景；不更改实际工作区。

## 交付说明

本次为小功能与界面调整，影响文件少于 20 个，版本升级至 2.8.3。提供 Windows x64 安装包和便携版，不自动安装。

绿色日历统计 ReqFlow 中的新建需求，不读取 Git 仓库提交记录。深色适配仅作用于关联目录设置弹窗，不更改应用整体主题。
