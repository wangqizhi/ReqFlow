# ReqFlow 1.3.0

- AI 需求：将整段想法整理成候选列表，或根据项目上下文提出建议；支持继续讨论、编辑与删除候选，确认后整组加入待执行。请求包含项目背景与引导词、最近 40 条需求、近 7 天最多 30 条 Git Log，以及 README.md、package.json、AGENTS.md、docs/architecture.md（存在时）。未关联目录或无 Git 时仍可使用项目背景与需求列表。
- 设置中的 OpenAI / Anthropic API 格式按钮等宽、同高，统一圆角与分隔线。
- 我的项目支持新建文件夹与拖动项目到文件夹；旧项目自动归入 default。分组保存在工作区，随导出与备份保留。
- Git 面板按 Add → AI 生成 Log → Commit → Push 展示。未暂存时提示先 Add；AI 请求携带实际暂存 diff，没有待提交需求也可以依据 diff 生成。无待 Add 变动时初始折叠，用户可展开操作。Push 使用当前分支的 Git 上游配置。
- 待执行默认按需求编号倒序，支持切换最新在前、最早在前、优先级。
