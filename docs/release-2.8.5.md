# ReqFlow 2.8.5

## 主要更新

- REQ-174：点击「发布」时，只有本地 Git 仓库、未配置远程仓库的项目也会先检查变动，暂存全部变动，使用现有 AI 功能根据暂存 diff 生成提交文案并提交，再运行发布脚本；只跳过 Push。
- 工作区没有变动时跳过暂存、AI 与提交；非 Git 目录继续直接运行发布脚本。配置远程仓库时保留提交后 Push 的原有流程。
- Git 状态检查、暂存、AI 生成或提交任一步骤失败时停止发布，避免带着未完成的提交继续执行脚本；终端继续显示当前步骤与脚本日志。

本次为小功能调整，版本升级至 2.8.5。生成 Windows x64 安装包、便携版和 SHA256 校验文件，不自动安装。
