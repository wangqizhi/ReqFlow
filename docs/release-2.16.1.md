# ReqFlow 2.16.1

## 主要更新

- 全局记忆的每个手动记忆输入框（常用技术方案、UI 设计要求、偏好与协作习惯、工程约定、经验与踩坑、环境与常用命令）新增「AI 填写」按钮，可分别调用已配置的 AI 供应商生成内容。
- AI 填写按条目检索各项目 Git 提交中的相关记录（含提交正文），并参考对应的项目文件（如 README、package.json、docs/ui-guidelines.md、CLAUDE.md）与近期完成需求的完成说明，跨项目归纳可复用内容。
- 已有内容会在其基础上补充修订，并避开其他条目已有的内容；生成长度按全局记忆剩余预留空间控制。
- 生成结果以「当前内容 / AI 生成」上下对比展示，可编辑后「应用到草稿」或放弃，保存设置后才写入记忆文件。
