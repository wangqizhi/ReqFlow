# ReqFlow 2.12.4

## 主要更新

- 修复 Server 更新、安装和卸载在 SSH 命令失败时仅显示退出码的问题：保留 SSH 标准错误，区分用户名或公钥认证失败、主机指纹校验失败、地址解析失败、端口拒绝与连接超时，并隐藏可能包含的凭据。
- 更新弹窗在没有已保存 SSH 目标时不再自动填入裸 IP，提示填写原部署的 `user@host`，避免 SSH 默认使用本机用户名而导致认证失败。
- 保留通过 SSH 配置指定用户的主机别名用法，以及更新成功后记住 SSH 目标的行为。

## 验证

- 回归覆盖 SSH 错误分类、详细原因保留、凭据隐藏及底层错误链。
- 对实际部署执行只读检查，确认原部署用户可连接。
