# ReqFlow 2.13.6

## 主要更新

- 修复发布流程缺少杀毒检查的问题：打包前扫描实际 Go 主程序，打包后扫描安装器；检测到威胁、扫描出错、超时或无明确通过结果时停止。
- GitHub 上传前重新检查主程序与安装包，避免依赖过期扫描结论；打包清单记录 SHA256、扫描时间、引擎与病毒库版本。
- 待验证列表始终展示可验证版本；完成任务时统一记录版本，支持本地及关联 Server Agent 的项目。
- 多实例关闭空闲窗口时保留共享任务；保护正在承载 Agent 终端的窗口，避免任务意外中断。
- 设置新增「提示词模板 → 核心需求」，支持编辑 CLI 指派提示词、动态占位词与恢复默认模板。

## 验证情况

- 本机 Defender 主程序和安装包扫描通过，CLI、SQLite、安装升级/卸载及基本 GUI 启动检查通过。
- 完整交互 UI 冒烟在 PowerShell 阶段超时，尚未全部通过。

排查证据与结论边界见 [Defender 告警排查](defender-investigation-2026-10-27.md)。
