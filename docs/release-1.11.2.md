# ReqFlow 1.11.2

- 设置 → 请求日志新增“记录发布请求日志”开关，默认开启，与 AI 请求日志独立保存。
- 发布请求日志实时记录构建、打包、版本检查、Git 推送和 GitHub 附件上传的阶段、输出、累计/阶段耗时与最终结果，每 2 秒刷新。
- 发布长时间没有输出时记录执行中状态；日志仅保存本机，保留最近 2000 条及约 512 KB，隐藏常见密钥字段。关闭后停止新增，保留已有记录。
- 设置页内容独立滚动，较低窗口高度下底部操作保持可见。
- 项目存在待验证需求时，点击「发布」先弹出确认浮层，列出待验证条目，可选择去验证或仍要发布。
- 设置浮层改版：各标签页的保存统一为底部「保存并完成」按钮，保存当前标签页后关闭；标签改为带边框底色的按钮样式，收紧标签与内容的间距；浮层固定高度，各标签页高度一致，内容区独立滚动。
- 项目设置区域：目录路径并入「AI 验证 / 新需求的默认设置」同一行，超长省略显示，悬停查看完整路径，区域高度更紧凑。

发布日志记录应用中发布按钮启动的脚本。终端直接执行发布脚本时，阶段与耗时显示在终端。
