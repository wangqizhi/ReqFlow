# ReqFlow 2.13.8

## 主要更新

- PowerShell 与发布终端入口合并为一个「终端」按钮，点击默认展开 PowerShell；发布页签仅在启动过发布或需要查看发布信息时出现，空闲的发布终端不再常驻页签。
- 终端支持选中即复制：在发布输出、PowerShell 与指派终端中拖选文本即复制到剪贴板，交互终端里 Ctrl+C 继续用于发送中断信号。
- 应用内更新进入安装步骤时，「安装」按钮宽度减半，同行新增「重新检测」按钮：强制查询 GitHub 最新版本，发现更新的版本时可直接下载新版安装包。
- 修复需求池中已延迟的需求不再显示勾选框、无法手动勾选的问题，恢复「全选跳过、仍可手动勾选」的既定行为。
