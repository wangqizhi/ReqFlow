# ReqFlow 2.8.8

## 主要更新

- REQ-176（验证退回修复）：终端最大化或调整尺寸时不再闪烁。遮罩改为在整段尺寸变化期间持续覆盖，尺寸稳定且 xterm 完成排版、实际渲染后再淡出显示内容；连续多帧尺寸变化不会露出中间画面。
- 加载过渡保持可见：从窗口开始最大化到渲染完成的整个过程中显示加载动画，结束后以 140ms 淡出过渡，不再出现「内容 → 加载 → 内容」的反复切换。
- 独立窗口打开期间同样保持遮罩，避免切换窗口时短暂露出旧画面。
- 界面检查新增连续多次尺寸变化的用例，确认遮罩不中断、内容保持隐藏，且稳定后完整显示日志。

## 交付说明

本次为样式与小功能修复，影响文件少于 20 个，版本升级至 2.8.8。生成 Windows x64 安装包、便携版及 SHA256 校验文件，不自动安装或上传。

- `npm run typecheck`、`npm run smoke`（Go 测试与 vet）通过。

- 界面检查新增原生窗口最大化用例：从独立终端窗口内部逐帧采样，确认最大化期间遮罩持续覆盖、内容保持隐藏，窗口稳定后恢复显示（`sawVeil`、`covered`、`settled` 均为 true）。
